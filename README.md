# OpenBank – Digital Banking UI (Prototype)

OpenBank is a responsive frontend (or full-stack) simulation of a modern digital banking experience. It includes dashboards for users, transaction tracking, and account summaries — built to practice enterprise-grade UI patterns and scalable state management.

---

## 💡 Use Case

- Simulated online banking experience
- Fetching and rendering user account info
- Displaying transactions and balances
- UI/UX focus on dashboarding and data integrity

---

## 🛠️ Tech Stack
